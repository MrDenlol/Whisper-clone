# Ручной прогон качества распознавания (ru)
#
# Юнит-тесты не проверяют качество ASR (синусоида — не речь), поэтому качество
# русского распознавания проверяется вручную на живой модели:
#
#   1. Скачайте модель:        .\scripts\download_model.ps1 -Model small
#   2. Синтезируйте/запишите каждую фразу в 16-битный WAV и прогоните:
#         WhisperFlowClone.exe --wav phrase01.wav
#      или надиктуйте фразу хоткеем и сравните вставленный текст.
#   3. Язык по умолчанию ru; для сравнения можно запустить --language auto.
#
# Ниже — фразы и ожидаемый вид результата. Модель не обязана давать побайтовое
# совпадение; важно, чтобы пунктуация/регистр были адекватными, а неречевые
# звуки не описывались текстом вида «(кашель)».
#
# --- Обычная речь: пунктуация и заглавные буквы -------------------------------
Привет, как дела?
Меня зовут Иван, и это локальное распознавание речи без облака.
Завтра встречаемся в три часа, не забудь про документы.
# --- Надиктованная пунктуация (dictionary.json) -------------------------------
напиши запятая потом текст              -> напиши, потом текст
первое точка с запятой второе           -> первое; второе
внимание вопросительный знак            -> внимание?
конец точка                             -> конец.
# --- Тексты, которые нормализация не должна ломать ---------------------------
открой https://example.com/docs?lang=ru -> открой https://example.com/docs?lang=ru
подключись к localhost:3000             -> подключись к localhost:3000
запусти python3 script.py               -> запусти python3 script.py
# --- Шум вокруг речи: не должен превращаться в описание звука ----------------
